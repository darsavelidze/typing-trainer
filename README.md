# 🏃 Fast Typing Trainer

Веб-приложение для тренировки скорости печати с сохранением статистики и аутентификацией пользователей.

## 📋 Возможности

- ✅ Регистрация и авторизация пользователей
- ✅ Тренировка скорости набора текста
- ✅ Сохранение и отслеживание статистики
- ✅ Личный кабинет с историей результатов

---

## 🛠️ Что нужно установить перед запуском?

### Для Windows:
1. **Python** — программа для запуска приложения
2. **Git** (опционально) — для скачивания проекта

### Для macOS/Linux:
- Обычно Python уже установлен, но если нет — нужно установить

---

## 📥 Пошаговая инструкция установки

### ШАГ 1️⃣ — Скачайте проект

Если у вас есть **Git**, откройте Терминал/Командную строку и введите:

```bash
git clone <repository-url>
cd fast-typing-trainer
```

Если нет Git — просто скачайте файлы проекта вручную и откройте папку `fast-typing-trainer` в Терминале/Командной строке.

**🔹 Для Windows:**
- Нажмите `Win + R`
- Введите `cmd` и нажмите Enter
- Перейдите в папку проекта командой `cd C:\путь\к\fast-typing-trainer`

**🔹 Для macOS/Linux:**
- Откройте Терминал (Applications → Utilities → Terminal)
- Введите `cd /path/to/fast-typing-trainer`

---

### ШАГ 2️⃣ — Создайте виртуальное окружение

Это специальная папка, где будут храниться все нужные программе библиотеки, отдельно от остальной системы.

**Для Windows:**
```bash
python -m venv venv
```

**Для macOS/Linux:**
```bash
python3 -m venv venv
```

После выполнения в папке проекта появится папка `venv`. ✅

---

### ШАГ 3️⃣ — Активируйте виртуальное окружение

Теперь нужно "включить" это окружение, чтобы использовать его.

**Для Windows:**
```bash
venv\Scripts\activate
```

**Для macOS/Linux:**
```bash
source venv/bin/activate
```

**Как узнать, что всё сработало?**
В начале строки в Терминале должно появиться `(venv)`:

```
(venv) C:\Users\YourName\fast-typing-trainer>
```

или

```
(venv) user@MacBook fast-typing-trainer %
```

---

### ШАГ 4️⃣ — Установите нужные библиотеки

Проект использует несколько библиотек Python. Установите их одной командой:

**Для всех (Windows, macOS, Linux):**
```bash
pip install -r requirements.txt
```

Программа сама скачает и установит:
- Flask (веб-фреймворк)
- Flask-SQLAlchemy (для работы с БД)
- Werkzeug (для безопасности паролей)

Процесс займёт 30-60 секунд. Ждите пока не завершится. ⏳

## 🚀 Запуск приложения

После установки всех библиотек запустите приложение:

```bash
python app.py
```

**Вы должны увидеть что-то подобное:**

```
* Running on http://127.0.0.1:5000

```

## 💻 Как использовать приложение?

1. **Откройте браузер** (Google Chrome, Firefox, Safari, Edge и т.д.)

2. **Перейдите на адрес:**
   ```
   http://localhost:5000
   ```
   
   или
   
   ```
   http://127.0.0.1:5000
   ```

3. **Вы увидите главную страницу** приложения

4. **Зарегистрируйтесь:**
   - Нажмите кнопку "Регистрация"
   - Введите логин и пароль
   - Подтвердите пароль
   - Нажмите "Зарегистрироваться"

5. **Авторизуйтесь:**
   - Введите ваши логин и пароль
   - Нажмите "Вход"

6. **Начните тренировку:**
   - На главной странице вы увидите тренировочный текст
   - Набирайте текст как можно быстрее и точнее
   - Система сохранит ваш результат автоматически

7. **Просмотрите статистику:**
   - Перейдите в "Профиль" или "Статистика"
   - Увидите все ваши результаты и прогресс

## ❓ Частые проблемы и решения

### Проблема: "Python не установлен"
**Решение:** 
- Скачайте Python с [python.org](https://www.python.org/downloads/)
- При установке обязательно отметьте галочку "Add Python to PATH"

### Проблема: "команда python не найдена" (на macOS/Linux)
**Решение:** Используйте `python3` вместо `python`
```bash
python3 -m venv venv
python3 app.py
```

### Проблема: "requirements.txt не найден"
**Решение:** Убедитесь, что вы находитесь в правильной папке (где находится файл app.py)

### Проблема: "CTRL+C не работает"
**Решение:** Попробуйте `CTRL+Z` (на Windows) или закройте Терминал

### Проблема: "Порт 5000 уже занят"
**Решение:** Измените порт в файле `app.py` (найдите строку `app.run()` и измените `port=5000` на другой номер, например `port=5001`)
