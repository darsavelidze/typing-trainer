# ⌨️ Fast Typing Trainer — тренажёр скорости печати с адаптивным алгоритмом

Веб-приложение для тренировки скорости набора текста с **адаптивным подбором слов** на основе взвешенной статистики. Приложение отслеживает скорость печати каждого слова и автоматически формирует персонализированные тренировки, делая акцент на словах, которые даются пользователю хуже всего.

## 📌 О проекте

Существующие тренажёры скорости печати предлагают случайный набор слов, не учитывая индивидуальные особенности пользователя. В результате человек тратит одинаковое время на слова, которые уже набирает быстро, и на те, которые вызывают затруднения.

Данный проект решает эту проблему: приложение **замеряет скорость набора каждого слова**, вычисляет **взвешенную скорость** (символов в секунду) и на основе этих данных **формирует персонализированные тренировки**, в которых приоритет отдаётся самым медленным словам.

### Ключевые особенности

- 🧠 **Адаптивный алгоритм** — взвешенная статистика скорости печати каждого слова (символов/сек) определяет приоритет слов в тренировке
- ⏱️ **Тест на 1 минуту** — классический формат с подсчётом WPM (слов в минуту) в реальном времени
- 📊 **Детальная статистика** — таблица с средним временем, количеством попыток, динамикой изменений и взвешенной скоростью
- 🔄 **Два режима** — случайный набор из топ-200 английских слов и адаптивная тренировка слабых слов
- 👤 **Аутентификация** — регистрация/вход, сохранение статистики в БД для каждого пользователя
- 🎨 **Живая подсветка** — посимвольная подсветка правильности ввода (зелёный/красный) в реальном времени

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/<ваш-username>/fast-typing-trainer.git
cd fast-typing-trainer
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
source venv/bin/activate        # macOS / Linux
# venv\Scripts\activate         # Windows
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

Это установит все необходимые библиотеки: Flask, Flask-SQLAlchemy и Werkzeug.

### 4. Запуск приложения

```bash
python app.py
```

Приложение будет доступно по адресу: **http://127.0.0.1:5000**

## 🎮 Как пользоваться

1. **Откройте браузер** и перейдите на `http://127.0.0.1:5000`
2. **Зарегистрируйтесь** — создайте аккаунт для сохранения прогресса
3. **Начните печатать** — таймер на 1 минуту запускается с первого нажатия клавиши
4. **Набирайте слова** — текущее слово подсвечивается посимвольно; нажмите пробел для перехода к следующему
5. **Изучите статистику** — таблица внизу показывает скорость набора каждого слова
6. **Тренируйте слабые слова** — нажмите «Practice Weak Words» для адаптивной тренировки

### Режимы тренировки

| Режим | Описание |
|-------|----------|
| **Restart** | Случайный набор из 200 наиболее частотных английских слов |
| **Practice Weak Words** | Адаптивный подбор: приоритет отдаётся словам с наименьшей взвешенной скоростью |

### Таблица статистики

| Столбец | Описание |
|---------|----------|
| Word | Слово |
| Avg time | Среднее время набора (сек) |
| Count | Количество попыток |
| Change | Динамика: ↑ быстрее / ↓ медленнее |
| Weighted speed | Взвешенная скорость (символов/сек) |

## 🔧 Как это работает

### Адаптивный алгоритм подбора слов

```
Пользователь набирает слово
       ↓
Замер времени от первого нажатия до пробела
       ↓
Вычисление взвешенной скорости: длина_слова / время (символов/сек)
       ↓
Обновление статистики в wordStats
       ↓
При выборе «Practice Weak Words»:
  → Сортировка всех слов по взвешенной скорости (по возрастанию)
  → Слова без статистики получают приоритет (score = 0)
  → Выбор 200 самых медленных слов
       ↓
Перемешивание и начало тренировки
```

### Формула взвешенной скорости


$$
\mathrm{weighted\_speed} = \frac{\mathrm{len(word)}}{t_{\mathrm{last}}}
$$

где $t_{\mathrm{last}}$ — время набора слова при последней попытке. Это позволяет учитывать текущий уровень навыка, а не усреднённый за всё время.

### Архитектура

```
Браузер (JS)                        Сервер (Flask)
┌──────────────┐                   ┌──────────────┐
│ typing-trainer│ ─── ввод ───→    │              │
│ statistics    │ ─── JSON ───→    │   app.py     │
│ main          │ ←── stats ──     │   SQLite     │
└──────────────┘                   └──────────────┘
```

- **typing-trainer.js** — ядро: рендеринг слов, посимвольная подсветка, таймер 60 сек, WPM
- **statistics.js** — сбор времени набора, расчёт взвешенной скорости, адаптивный подбор
- **main.js** — интеграция: автосохранение статистики на сервер через `/save_stats`
- **app.py** — Flask-сервер: регистрация, авторизация (Werkzeug), хранение статистики (SQLAlchemy + SQLite)
